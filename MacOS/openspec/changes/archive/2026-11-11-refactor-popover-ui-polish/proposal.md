# Proposal

## Why

菜单弹窗现在是 240pt 的纯文本列表。空状态只有一句「没有账户」，账户行没有站点与用户名分层，底部操作也是竖向按钮。它能用，但看起来不像一个常驻菜单栏工具。

## What Changes

- 弹窗固定宽 300pt、最小高 320pt，使用系统材质背景、圆角和细边框，不再使用纯灰底。
- 空状态居中显示 `lock.badge.clock`、标题「暂无 TOTP 账户」、一句说明，以及胶囊按钮「添加第一个账户」。该按钮打开现有录入窗口，不新建账户。
- 每个账户始终显示首字母徽章、站点名、用户名、等宽验证码和环形倒计时。悬停只改变圆角卡片背景，不再用来显示或隐藏验证码。
- 单击整行仍复制验证码，并把该行反馈临时换成「已复制」。
- 底部改成一行工具栏：左侧显示「共 X 个账户」，右侧是新增、设置和退出图标。设置仍禁用。
- 明暗模式都使用系统语义色。不改 TOTP 计算、Keychain、元数据仓库或保存协议。
- 不新增屏幕扫描或 CSV 导入，因此不定义屏幕录制权限或 CSV 列映射。

## Capabilities

### New Capabilities

- `popover-presentation`: 规定弹窗尺寸、材质、空状态、账户行和底部工具栏的可见布局。

### Modified Capabilities

- `totp-list`: 验证码改为始终可见；空状态增加一个打开录入窗口的按钮，但空仓库仍不创建账户。
- `app-skeleton`: 新增、设置和退出从竖向菜单项改到底部工具栏，行为不变。

## Impact

- `Sources/TOTPApp/AccountList.swift` 与 `Sources/TOTPApp/TOTPApp.swift` 的弹窗布局。
- 不修改 `TOTPCore` 的算法、存储协议或 Base32 解码。
